## How to Contribute
We welcome contributions from everyone—whether you are a Rust developer, a Circom cryptographer, or a WebGL designer! 

### Getting Started
1. **Developers**: Check out our `README.md` for instructions on how to run the Soroban contracts and Next.js frontend locally. 
2. **Issues**: Look for GitHub issues labeled `good first issue` or `help wanted` to get started.
3. **Pull Requests**: When contributing code, please submit a Pull Request to the `master` branch. Ensure that all CI checks pass (`cargo test`, `cargo clippy`, and Circom compilation).

### Areas of Focus
- **ZK Circuit Optimization**: We are always looking for ways to reduce constraint counts in our Circom circuits.
- **Frontend / 3D Graphics**: Help us improve our React Three Fiber vault visualizations.
- **Soroban Contracts**: Optimizing our escrow engine and liquidation auctions.

## Bug Bounty & Security
If you are a security researcher, please read our [SECURITY.md](SECURITY.md) to learn about our Bug Bounty program and the correct procedures for responsibly disclosing vulnerabilities. Do not open public issues for security vulnerabilities.

## Code of Conduct
We are committed to providing a welcoming and inspiring community for all. Please adhere to respectful, inclusive, and professional behavior when participating in Astra repositories and social channels.
